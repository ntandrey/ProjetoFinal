# Desconfia!

Site educativo desenvolvido como projeto da faculdade, com o objetivo de conscientizar as pessoas sobre os golpes digitais mais comuns e ensinar como se proteger deles.

## Sobre o projeto

O **Desconfia!** possui informações sobre diferentes tipos de golpes que estão por toda a internet. Cada página explica um tipo de golpe, mostra exemplos comuns e traz dicas de proteção.

## Páginas

- **Início:** apresentação do site e acesso aos tipos de golpe
- **Golpes do Pix**
- **Mensagens falsas de bancos**
- **Links suspeitos**
- **Lojas virtuais fraudulentas**
- **Falsas ofertas de emprego**
- **Sobre:** informações sobre o projeto
- **Contato**

## Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox)
